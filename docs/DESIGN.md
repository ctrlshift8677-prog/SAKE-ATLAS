# SAKE ATLAS 設計說明

## 概念
御朱印帳。每款酒是一頁直書的御朱印（縣名、毛筆酒名、漢字日期、酒造朱印），每個縣是一枚收集到的印。保留原有的水墨山水背景與可點選的日本地圖。

## 字型
- 霞鶩文楷 TC：酒名、標題、朱印、直書文字
- Noto Sans TC：內文、按鈕、表單

## 紙
酒標和紙：白色楮紙，細短纖維紋理（static/hosho-light.webp／hosho-dark.webp），邊緣有細細的纖維毛邊（static/label-edge.png，以 -webkit-mask-box-image 套用；Firefox 會顯示為直角邊），對角兩處稀疏的金砂子（static/kinpaku.webp）。用在首頁與縣別頁的右頁、沒有照片時的酒款大封面；並排的酒卡只用紙紋、不做毛邊。

## 地圖
和紙剪片貼在水墨畫上：每個縣有紙紋與細陰影，顏色深淺依喝過的款數；海岸外有四圈水紋線，桌機上會緩慢往外擴散。滑過時該縣浮起、金線沿邊描一圈，其他縣淡出，並出現浮動標籤。載入時各縣由北往南依序出現。觸控裝置第一次點是預覽，第二次點才進入縣別頁。

## 各縣水墨風景
每個縣一幅代表風景（例如山形的月山與最上川、熊本的阿蘇），放在右頁的下半部，朱印蓋在畫上，左側直書畫題。深色模式會反相成淡墨。

## 元件
- `.seal`：朱印。文字直書、白字朱底、內框細線、墨色顆粒遮罩（seal-grain.png）、與墨字重疊時以 multiply 混合。
- `.g-page`：御朱印頁卡片封面，字級用容器寬度（cqw）縮放，任何尺寸比例一致。
- `.leaf`：首頁與縣別頁右側的和紙頁。
- `.fold-track`：折帖（經摺本）橫向捲動，捲入畫面時展開。

- 風味：香氣輪（`.wheel`）與利き猪口（`.cup`，俯視的品酒杯）。杯中酒色、漣漪快慢與氣泡依口感標籤，滑過口感詞時杯中的酒會盪一下。

## 酒款頁排版
標題（酒名、酒造與縣）→ 心得 → 規格帶（只列有資料的欄位，精米步合附小米粒與倒數）→「這一杯」面板（德利斟酒動畫、香氣與口感詞、香氣輪與利き猪口並排、風味說明）→ 品飲紀錄。不顯示規格參考來源。

## 斟酒（酒款頁「這一杯」）
和紙面板上，墨線德利（とっくり）從右上傾入、把酒斟進杯裡，斟完退場；旋轉軸就是壺口，酒柱永遠從口沿落下。壺口可見酒色（金／白濁／琥珀／櫻粉與杯中一致）。倒多滿依喜歡程度；4.8 分以上滿到溢出、沿杯壁流下積成一小灘。
- 香氣＝「香の粒」：杯口上方升起的微粒（小圓點＋柔光暈），顏色依香氣家族；滑過香氣詞或香氣輪時，對應的粒會亮起並馬上升一顆。
- 開啟「減少動態」時：德利、香の粒、酒柱不顯示，杯中酒量固定。

## 殿堂
喜歡程度 4.5 分以上（build.py 的 DENDO）的酒，在名字旁的紙面上蓋一枚直書「殿堂」朱印：酒卡蓋在酒名右側（15px 字），酒款頁蓋在大標題右上（24–32px）。蓋印動畫：朱印放大、傾斜、略帶模糊地從上方壓下，回彈定位，印泥在紙上微微暈開一圈；酒卡在進入畫面時蓋，酒款頁在打開時蓋。不蓋在照片上——朱印用 multiply 吃進和紙才有印泥質感。開啟「減少動態」時直接顯示。

## 照片
照片以品飲編號命名（T00025.jpg）放進 photos/，建置時自動對到那次品飲所屬的酒：每支酒用「最近一次」有照片的品飲當封面，其他次的照片放進那一次的品飲紀錄。也仍接受以酒款 ID 或酒名命名的照片。照片不裁切：只縮小、保留原始比例。酒卡（列表、折帖、風味相近／同產地等橫列、首頁照片）一律用 9:16 的框，整排高度一致、頂端對齊；少數不是 9:16 的照片完整放進框裡，上下留和紙。酒款頁大圖跟著照片自己的比例。照片沒有閃光、反光或放大效果，滑過只有輕微的傾斜。

## 照片 lightbox
酒款頁的大張照片可點開全螢幕（深色底、✕ 或 Esc 或點擊關閉），鍵盤 Enter／空白鍵也能開啟。

## 酒卡香氣色條
有香氣紀錄的酒，封面底部有一條 4px 細色帶：一段一個香氣詞，顏色＝香氣家族（與酒款頁的香の粒、香氣輪同色）。卡片牆一眼看出果香系、米麴系、熟成系。

## 從酒卡到酒款頁
點酒卡時，照片從卡片位置放大、直接變成酒款頁的大圖（跨頁 View Transitions，約 0.6 秒），其餘內容淡出再淡入；返回列表時照片飛回原本那張卡片。開啟「減少動態」時不播。

## 地圖水彩暈開
首頁與縣別頁的地圖：滑過（觸控為點一下）有紀錄的縣，剪片浮起、先變回一張淡色和紙，再由該區域自己的顏色從中心暈開，像顏料滴在濕紙上——中間淡、顏料在縣界邊緣堆積得較深（水痕），縣外有一片極淡的同色在和紙上化開。濃淡依喝過幾款（--k）。不用黑墨（黑色在彩色的縣上顯髒）。離開後浮片落回原位，顏色在兩秒內慢慢褪回，快速掃過地圖會留下一道漸淡的色痕。
實作：每次滑過由 JS 依區域色產生該縣專用的徑向漸層；濾鏡 map-ink-bleed / map-ink-wash / map-ink-pool（feTurbulence＋feDisplacementMap 做毛邊）。名稱加 map- 前綴，避免和利き猪口的 ink-bleed 撞名。開啟「減少動態」時不播暈開動畫。

## 品飲紀錄分頁
同一支酒喝過兩次以上時，品飲紀錄改成同頁切換：上方一排分頁（日期＋地點），紀錄本身是可以左右滑動的橫向卷軸（手機用手指、電腦用觸控板），一次停一筆，高度跟著目前那一筆；分頁、手機上的圓點、「這一杯」的斟酒分頁全部同步。手機上標題旁提示「左右滑動切換」。可用方向鍵切換。沒有 JavaScript 時全部直向列出。

## 酒款頁大圖左右滑
一支酒有兩張以上照片（不同次品飲，或同一次好幾張）時，酒款頁大圖本身可以左右滑動，右上角顯示「1 / 2」、下方有圓點；電腦滑過大圖會出現左右箭頭，也可用方向鍵。滑到哪一張，品飲紀錄與「這一杯」就切到那一次；反過來點分頁，大圖也會滑到那一次的照片。同步時不會讓頁面上下跳動。點大圖放大時顯示目前那一張。
